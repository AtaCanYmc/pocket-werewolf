# Anti-Slop Audit Report #001

- **Date:** 2026-11-15
- **Project:** Pocket Werewolf
- **Scope:** Full codebase review against Antislop rules (R-01 through R-40)

## Findings List

1. **[HIGH] R-02 (Copywriting):** Em dash (`—`) present in Turkish localization string (`src/i18n/translations.ts:441`).
2. **[HIGH] R-39 (Accessible Semantics):** `maximum-scale=1.0` and `user-scalable=no` declared in viewport meta tag (`index.html:11`), restricting user zooming.
3. **[HIGH] R-39 (Interaction Affordances):** Base CSS layer lacks explicit `cursor: pointer` on interactive controls and `cursor: not-allowed` on disabled states (`src/index.css`).
4. **[HIGH] R-39 (Accessible Motion):** Missing `@media (prefers-reduced-motion: reduce)` media query override to honor reduced-motion preferences (`src/index.css`).
5. **[HIGH] R-32 (Keyboard Accessibility):** Global `:focus-visible` outline indicator missing for keyboard navigation (`src/index.css`).
6. **[HIGH] R-39 (Accessible Names):** Icon-only header controls rely on `title` attribute without explicit `aria-label` attributes (`src/components/common/Header.tsx`).
